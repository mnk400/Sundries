# Markdown test vault

Select this folder in **Doist → Settings → Sources → Markdown**.

The fixture includes:

- standard, starred, plus-sign, and nested checkbox lists;
- completed tasks that should not appear in the open-task list;
- overdue, today, tomorrow, upcoming, and unscheduled tasks;
- both `📅 YYYY-MM-DD` and `@due(YYYY-MM-DD)` date syntax;
- ordinary Markdown that completion write-back should preserve.
