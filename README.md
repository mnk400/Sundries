# Sundries

Sundries is a native macOS menu-bar todo companion. It gathers tasks from the places they already live, beginning with Markdown files and expanding through source adapters over time.

> Sundries is currently an early alpha. Data formats and behavior may change.

## Current features

- Liquid Glass menu-bar interface for reviewing and capturing tasks
- Overdue and due-today or total-open menu-bar counts
- Markdown folder scanning and checkbox task support
- Destination selection when adding a Markdown task
- Inline due-date presets and calendar selection
- Completion feedback with Undo
- Keyboard-friendly composer and navigation

Apple Reminders is planned as the next source integration.

## Requirements

- macOS 26 or later
- Xcode 26 or later
- Swift 6

## Development

Open `Sundries.xcodeproj` and run the `Sundries` scheme.
